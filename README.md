# Simple Calculator in C

## About
My first C programming project, built to practise basic programming concepts and arithmetic operations.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Division-by-zero error handling
- Invalid operator handling

## Concepts Used
- Variables and data types
- User input and output
- Switch statements
- If-else conditions
- Arithmetic operators

## How to Run
1. Open `calculator.c` in a C compiler.
2. Compile and run the program.
3. Enter two numbers and an operator.
4. View the result.
